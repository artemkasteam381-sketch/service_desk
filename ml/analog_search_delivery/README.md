# Поиск похожих обращений поддержки

Этот проект ищет до пяти полезных исторических аналогов по тексту нового русскоязычного обращения.

В выдаче сохраняются исходные данные исторической записи:

- ID обращения;
- исходный текст;
- вид запроса;
- историческая линия поддержки;
- результат работ;
- другие варианты из той же группы дубликатов.

Если подробного решения в истории нет, система его не придумывает. Категория нового обращения пока не используется: классификатор другого участника команды будет подключаться отдельным дополнительным признаком.

## Что уже реализовано

Сравниваются три метода:

1. `bm25` — быстрый лексический поиск по словам;
2. `bge` — семантический поиск по эмбеддингам `BAAI/bge-m3`;
3. `hybrid` — объединение рангов BM25 и BGE-M3.

Поиск выполняется по всей переданной истории. В топ-5 не допускаются повторения одной группы дубликатов. Одинаковые тексты с разными категориями или результатами сохраняются внутри `duplicate_variants`.

## Быстрый просмотр без запуска моделей

Откройте:

- `analog_query.json` — пример ответа поиска;
- `metrics_ai.json` — готовые метрики;
- `judgments_ai.csv` — все 384 оценки с объяснениями;
- `analog_review/review.html` — интерфейс просмотра и собственной разметки.

Предварительные результаты по ИИ-разметке:

| Метод | Доля результатов с оценкой 1 или 2 в топ-5 | Запросы с хотя бы одним результатом оценки 2 | pool nDCG@5 |
|---|---:|---:|---:|
| BM25 | 48,0% | 42,5% | 0,462 |
| BGE-M3 | **61,5%** | 52,5% | **0,599** |
| Hybrid | 59,0% | **57,5%** | 0,583 |

Оценки означают:

- `0` — другая проблема или бесполезный аналог;
- `1` — похожий контекст или симптом, но практической пользы мало;
- `2` — аналог полезен для диагностики или следующего шага.

Это предварительная разметка ИИ, а не подтверждённая экспертная оценка. В `judgments_ai.csv` колонка `uncertain=true` отмечает 86 пар, которые особенно желательно проверить человеку.

## Как посмотреть и пересчитать метрики

В notebook задайте:

```python
from support_search.evaluation import score_pool, paired_interval

RUNS = PROJECT / "analog_review/runs.json"
JUDGMENTS = PROJECT / "judgments_ai.csv"

scores = score_pool(RUNS, JUDGMENTS)
print(json.dumps(scores["summary"], ensure_ascii=False, indent=2))

print(paired_interval(RUNS, scores, "bm25", "bge"))
print(paired_interval(RUNS, scores, "bm25", "hybrid"))
print(paired_interval(RUNS, scores, "bge", "hybrid"))
```

Положительная `mean_group_delta_ndcg` означает преимущество второго метода над первым. Если доверительный интервал `ci95` пересекает ноль, убедительного различия на этой выборке нет.

Сейчас BGE-M3 и Hybrid предварительно лучше BM25. Убедительного различия между BGE-M3 и Hybrid не обнаружено.

## Интерфейс для сайта

Основной вызов:

```python
response = engine.search(raw_text, method="hybrid")
```

`response["results"]` содержит до пяти разных групп. У результата есть:

```text
id
original_text
topic
support_line
result
source_url
duplicate_group
duplicate_variants
category_conflict
ranking_score
```

Правила отображения:

- если `result` пустой, показать «Решение в истории не указано»;
- если ссылки нет, показать ID записи;
- `duplicate_variants` можно раскрывать дополнительным списком;
- `ranking_score` не является вероятностью и не должен отображаться как процент уверенности;
- историческая линия — факт прошлой обработки, а не гарантированная рекомендация маршрута.

## Производительность текущего прототипа

На пяти коротких запросах, CPU и двух потоках:

- BM25, медиана — около 1,1 мс;
- BGE-M3, медиана — около 57,8 мс;
- Hybrid, медиана — около 54,8 мс;

- первый холодный запрос — около 10,9 с;
- наблюдавшийся пик памяти общего процесса — около 1,73 ГБ.

Это небольшая локальная проверка, а не нагрузочный тест сервиса. Модель следует загружать и прогревать до начала демонстрации.

## Известные ограничения

- Разметка качества пока выполнена ИИ и требует выборочной проверки командой.
- Три из 40 проверочных запросов стали пустыми после парсера и получили пустую выдачу.
- Найден как минимум один почти дословный дубликат, который прежняя группировка не объединила — пара `pair_index=242`.
- Текущий эксперимент использует `text_core`; добавление темы и fallback для пустого ядра нужно проверять отдельным запуском.
- В поле `Результат работ` часто записан только статус вроде «Решение предоставлено», без подробной инструкции.
- Полезный аналог может отсутствовать в истории; обученного порога отказа пока нет.
- Проверка проведена на ранее использовавшейся validation-части. Для финального заявления нужен отдельный test.
- Классификатор и cross-encoder reranker ещё не участвовали в этом сравнении.
