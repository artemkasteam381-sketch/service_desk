# Помощник Service Desk

Сервис для категоризации обращений, рекомендации линии поддержки,
поиска похожих случаев и анализа SLA.

## Текущее состояние

Создан каркас интерфейса. Данные и модели пока не подключены.

## Локальный запуск

Рекомендуется использовать отдельное виртуальное окружение Python.

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустить приложение:

```bash
python -m streamlit run app.py
```

## Работа с Git

- Работа ведётся в ветках `feature/...`.
- Изменения попадают в `main` через Merge Request.
- Прямой push и force-push в `main` не используются.
- CI/CD не используется. Проверки выполняются локально.
