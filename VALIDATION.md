# Проверка комплекта

Проверен именно финальный `catboost_confidence` из архива результатов
`metadata_results_20260922_023105.zip`.

- Успешно загружены сохранённые TF-IDF, базовые классификаторы и CatBoost.
- Проверены порядок 16 классов, схема признаков, подготовка входа и топ-3.
- Замена исходного «Вида запроса» и добавление поля «Результат работ»
  не изменяют прогноз. Пустое описание отклоняется.
- Через Streamlit AppTest проверены заполнение формы, 13 полей регистрации,
  сравнение с текущим видом, отправка и отображение трёх рекомендаций.
  В этой проверке использовался сохранённый реальный эмбеддинг RuBERT.
- Отдельно выполнен успешный прогноз нового текста через `check_classification.py`:
  скачивание RuBERT, токенизация, вычисление эмбеддинга, базовые модели и CatBoost.
  Эта проверка выполнялась без подмены эмбеддингов.

Проверочная среда: Python 3.12, scikit-learn 1.6.1, CatBoost 1.2.10,
transformers 5.16.1, Streamlit 1.64.0; новый текст обработан на CPU с PyTorch 2.14.0+cpu.
Для установки в проекте зафиксирован PyTorch 2.11.0 из исходного обучающего экспорта.
Точное воспроизведение всей исходной среды Python 3.13.15 / PyTorch 2.11.0
в этой проверке не выполнялось.

Эти проверки подтверждают работоспособность интеграции. Качество на новых данных
они не измеряют: значение F1 weighted 0,765104 взято из OOF-результатов вашего запуска.
Существующие `src/ui/dispatcher_tab.py` и `src/ui/analytics_tab.py` не были приложены,
поэтому проверялась самостоятельная форма `classification_demo.py`.
