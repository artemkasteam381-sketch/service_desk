# Экспорт классификатора

В комплекте размещён финальный `catboost_confidence` из результатов
`metadata_results_20260922_023105.zip`. Его OOF F1 weighted — 0,765104.

Для обновления используйте `python tools/export_classifier.py НОВЫЕ_РЕЗУЛЬТАТЫ.zip`.
Все файлы экспорта должны обновляться вместе. После замены перезапустите сервис.

Веса исходного энкодера `cointegrated/rubert-tiny2` загружаются при первом прогнозе
и затем используются из кеша Hugging Face. Таблица эмбеддингов обучающих обращений
не нужна для обработки новых текстов.
