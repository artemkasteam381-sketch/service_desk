# Подключение маршрутизации и поиска аналогов

1. Распакуйте содержимое архива в корень репозитория с заменой
   `src/ui/dispatcher_tab.py`.
2. Запустите ML-сервис в первом терминале:

   ```powershell
   .\.venv-routing\Scripts\python.exe ml\support_service_weights\app.py --port 8765
   ```

3. Запустите Streamlit во втором терминале:

   ```powershell
   python -m streamlit run app.py
   ```

Во вкладке «Помощь диспетчеру» появится блок «Маршрутизация и похожие
обращения». Дополнительные зависимости основному приложению не нужны.

Если ML-сервис работает по другому адресу, задайте переменную окружения
`SUPPORT_SERVICE_URL` с полным адресом endpoint `/api/predict`.
